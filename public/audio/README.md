# Ambient Audio Assets

Everstep's Microsoft Store release includes seven licensed recordings in this directory. The raw MP3 files are deliberately not tracked in the public repository because Pixabay does not permit unchanged content to be redistributed on a standalone basis.

For a local release build, download the recordings from the source pages in [AUDIO_CREDITS.md](../../AUDIO_CREDITS.md), accept the license shown by Pixabay, and save them with these names:

```text
rain.mp3
cafe.mp3
thunderstorm.mp3
wind-leaves.mp3
ocean.mp3
forest.mp3
fire.mp3
```

Keep the source page, creator, download date, and license record whenever a recording is replaced.
