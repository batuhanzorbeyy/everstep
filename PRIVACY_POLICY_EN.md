# Everstep Privacy Policy

**Effective date:** July 29, 2026

Everstep is designed to work offline and with privacy by default.

## Data collection

Everstep does not collect, sell, rent, analyze, or transmit personal information or usage data. The app contains no advertising SDK, analytics SDK, account system, or cloud synchronization service.

## Data stored on the device

Tasks, settings, timer state, focus-session history, achievements, and preferences are stored locally on the user's device through the application's local storage. This information remains under the user's control.

## Exports and backups

JSON backups, CSV reports, and PDF reports are created only when the user explicitly requests them and chooses a save location. Everstep does not upload those files.

## Notifications and audio

Desktop notifications are generated locally and can be disabled in Settings. Ambient recordings are bundled with the application and played locally; playback does not contact an external service.

## Internet access

The current version does not require an internet connection for its features and does not send application data to a remote server.

## Deleting data

Users can delete all locally stored Everstep data from **Settings > Data > Delete all data**. Uninstalling the application may also remove application data depending on Windows settings.

## Changes

If future versions introduce optional online features, this policy will be updated before those features are released.

## Contact

For privacy questions, use the support contact shown on Everstep's Microsoft Store listing.
