# 製品名
Everstep

# 短い説明
Pomodoro セッション、タスク、環境音、わかりやすい生産性分析で集中を保ち、仕事を完了しましょう。

# 説明
Everstep は、日々の作業をシンプルにするために設計されたモダンな Pomodoro・集中支援アプリです。タイマーを開始し、取り組むタスクを選択して、進捗を日ごとに確認できます。

集中時間、短い休憩、長い休憩を自由に設定して、自分のリズムを作れます。カテゴリー、優先度、メモ、予定 Pomodoro 数を使ってタスクを計画し、完了した各セッションがタスクをどのように前進させるか確認できます。

週間グラフ、12週間の集中カレンダー、1日の目標、集中スコア、連続記録により、習慣を可視化できます。ホワイトノイズ、ピンクノイズ、ブラウンノイズ、雨、カフェ、海、森などの集中サウンドはオフラインで利用できます。

Everstep はアカウント不要で、広告を表示せず、利用データをサーバーへ送信しません。タスク、設定、セッション履歴はコンピューター内に保存されます。必要に応じて JSON バックアップ、CSV レポート、印刷可能な PDF レポートを作成できます。

# 製品機能
集中、短い休憩、長い休憩の時間をカスタマイズ
カテゴリー、優先度、メモ、予定 Pomodoro 数を含むタスク管理
1日の目標、集中スコア、連続記録
週間グラフと12週間のアクティビティヒートマップ
6種類のテーマとカスタムアクセントカラー
オフラインで利用できる集中サウンド
デスクトップ通知とシステムトレイ連携
JSON バックアップ、CSV・PDF レポート
キーボードショートカットと集中モード
トルコ語、英語、スペイン語、日本語、ドイツ語、イタリア語、アゼルバイジャン語のインターフェース
Windows 言語の自動検出
アカウント、広告、分析、クラウド追跡なし

# 新機能
バージョン 1.3.0 では、日本語、ドイツ語、イタリア語、アゼルバイジャン語の完全な翻訳を追加しました。Everstep は、Windows 言語の自動検出、地域に合わせた日付と時間、システムトレイ操作、通知、レポート、集中サウンド、タスク、統計、設定を含む7つのインターフェース言語に対応しました。既存のセキュリティ保護、オフライン動作、承認済みロゴ、自動テーマコントラストは維持されています。

# 認定に関する注意
アカウントやサインインは不要です。すべての機能はオフラインでテストできます。デスクトップ通知は設定で無効にできます。アプリは個人情報を収集または送信しません。
