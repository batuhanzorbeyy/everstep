# Məhsulun adı
Everstep

# Qısa təsvir
Pomodoro sessiyaları, tapşırıqlar, mühit səsləri və aydın məhsuldarlıq göstəriciləri ilə fokusunu qoru və işlərini tamamla.

# Təsvir
Everstep iş rejimini sadələşdirmək üçün hazırlanmış müasir Pomodoro və fokus tətbiqidir. Taymeri başlat, üzərində işlədiyin tapşırığı seç və irəliləyişini gündən-günə izlə.

Fokus, qısa fasilə və uzun fasilə müddətlərini fərdiləşdirərək öz ritmini qur. Tapşırıqları kateqoriya, prioritet, qeyd və təxmini Pomodoro sayı ilə planlaşdır, sonra tamamlanan hər sessiyanın işi necə irəli apardığını gör.

Həftəlik qrafiklər, 12 həftəlik fokus təqvimi, gündəlik hədəflər, fokus balı və ardıcıllıq izləmə vərdişlərini görünən edir. Ağ, çəhrayı və qəhvəyi küy, yağış, kafe, okean və meşə kimi fokus səsləri tam oflayn işləyir.

Everstep hesab tələb etmir, reklam göstərmir və istifadə məlumatlarını serverə göndərmir. Tapşırıqlar, parametrlər və sessiya tarixçəsi kompüterində qalır. Ehtiyac olduqda JSON ehtiyat nüsxəsi, CSV hesabatı və çap edilə bilən PDF hesabatı yarada bilərsən.

# Yeniliklər
1.3.0 versiyası yaponca, almanca, italyanca və azərbaycanca tam tərcümələr əlavə edir. Everstep artıq Windows dilinin avtomatik aşkarlanması, lokallaşdırılmış tarix və müddətlər, sistem treyi əməliyyatları, bildirişlər, hesabatlar, fokus səsləri, tapşırıqlar, statistika və parametrlər daxil olmaqla yeddi interfeys dilini dəstəkləyir. Mövcud təhlükəsizlik qorunmaları, oflayn iş rejimi, təsdiqlənmiş loqo və avtomatik tema kontrastı dəyişməz qalır.

Hesab və giriş tələb olunmur. Bütün funksiyalar oflayn sınaqdan keçirilə bilər. Masaüstü bildirişlərini Parametrlərdən söndürmək mümkündür. Tətbiq şəxsi məlumat toplamır və ötürmür.
