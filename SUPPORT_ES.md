# Soporte de Everstep

Everstep funciona sin conexión y no requiere una cuenta.

Para solicitar ayuda, incluye:
- Versión de Everstep
- Versión de Windows
- Una descripción breve del problema
- Una captura de pantalla, cuando sea útil

Sustituye esta sección por tu correo público de soporte o página de ayuda antes de enviar la aplicación a Microsoft Store.
