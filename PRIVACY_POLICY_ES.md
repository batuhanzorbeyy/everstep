# Política de privacidad de Everstep

**Última actualización:** 27 de julio de 2026

Everstep es una aplicación de productividad que funciona localmente. No requiere una cuenta, no muestra anuncios y no utiliza servicios de análisis.

## Datos que procesa la aplicación

Everstep guarda en el dispositivo las tareas, la configuración del temporizador, el historial de sesiones y las preferencias de apariencia e idioma. Estos datos se utilizan únicamente para ofrecer las funciones de la aplicación.

## Recopilación y transferencia de datos

Everstep no recopila, vende ni comparte datos personales. La aplicación no envía tareas, sesiones, preferencias ni estadísticas a ningún servidor.

## Copias de seguridad e informes

Las exportaciones JSON, CSV y PDF solo se crean cuando el usuario las solicita y se guardan en la ubicación elegida por el usuario.

## Eliminación de datos

El usuario puede borrar todos los datos desde Configuración > Datos. Desinstalar la aplicación también elimina los datos locales conforme al comportamiento de Windows para los datos de la aplicación.
